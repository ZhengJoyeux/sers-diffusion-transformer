# SERS 条件谱图扩散生成与 Transformer 识别

本仓库研究水、土壤基质下 DEL、CHL、TEB 的单药、双药和三药组合。当前 main 推荐两个分别训练的模型：**D4.31 第20轮二维曲线图 DiT 生成模型**，以及 **T3.32 图像 CNN＋Transformer 主体与 T3.33 第4轮三元修正组成的识别模型**。

此次只更新必要的源码和新增文件，不删除旧对照，不上传数据、权重、运行日志或缓存。T3.33 识别代码已是保留版本，不因本次生成端更新而重训或改写。

## 生成模型与数据流

126个条件共享一个DiT，条件字符串如 `DEL-H_TEB-S_water` 由规则解析为14维条件向量。没有自由文本编码器。PCA底谱、残差变换、强度归一化均使用对应真实训练谱拟合。实际扩散对象是二维曲线像素；旧U-Net与一维DiT代码仍可用于历史对照。

```mermaid
flowchart TD
    X[真实训练光谱与有效区掩码] --> P[训练集拟合的条件PCA先验与残差桥接]
    P --> R[固定坐标渲染1920×768曲线图]
    C[农药／等级／基质：14维条件] --> D[12层adaLN DiT：二维像素去噪]
    R --> D
    T[扩散时间步与噪声] --> D
    D --> L[图像与光谱损失＋D4.31导数边界目标]
    L --> W[全参数微调20轮：AdamW与EMA]
    W --> S[EMA模型：100步DDIM采样]
    P --> B[固定轴内同条件整条先验重抽]
    B --> S
    C --> S
    S --> Q[解码成光谱：PCA spread／QQ／均值校准]
    Q --> G[完整支持与最终交付保护]
    G --> O[通过检查后导出光谱与谱图]
```

二维范围固定为归一化[-1.5,1.5]。先验越界时整条重抽，记录审计；不逐点裁剪、不修改坐标、不放宽最终保护。D4.31辅助损失预算2%指损失值上限，不代表梯度上限。其训练扩展保留实际实验文件名和SHA256保护。

生成及评价命令见 [diffusion/README.md](diffusion/README.md)。新入口默认使用选定EMA权重、每条件50条；生成及评价输出写入新目录。常规评价直接运行，**不会先加载FID，也不会下载FID权重**。

## 识别模型与数据流

识别端保持当前T3.33：从数值光谱绘制共享尺度折线图，以二维CNN和Transformer提取特征，结合17个峰窗口数值证据，预测三种农药存在概率和有序等级。推理不输入真实标签、文件名或组合ID。

```mermaid
flowchart TD
    X[单条光谱与实测掩码] --> I[共享asinh尺度曲线图]
    I --> C[轻量CNN：坐标通道与纵向曲线矩]
    C --> E[6层Transformer＋残差Adapter]
    E --> Q[三药峰引导Query]
    X --> N[17峰数值证据]
    N --> Q
    Q --> P[三药存在概率]
    Q --> F[混合物浓度融合与投影]
    P --> F
    F --> H[CORN等级头]
    H --> R[T3.33：仅对预测三元的DEL／TEB小幅修正]
    N --> R
    P --> R
    R --> O[存在概率与S／M／H等级；分类和CHL保持]
```

T3.35头微调没有合格提升；T3.36终端摘要同样记录未获合格提升，正式报告尚未收录。两者保留为对照，不自动替代T3.33。识别端的 [使用说明](transformer/README.md)、[当前加载接口](transformer/current_recognition.py) 和模型源码保持原样。

## 当前验证结果

生成端比较9组同预算实验，每组126个条件、每条件50条生成谱，以4条真实验证谱为参考；只有一个训练种子。

| 轮次 | 组别 | 一阶导数Pearson ↑ | 绝对边界跳变量 ↓ |
|---|---|---:|---:|
| 5 | control | 0.796381 | 6.575198 |
| 5 | D4.31 | 0.802191 | 6.316328 |
| 5 | D4.32 | 0.801564 | 6.337113 |
| 10 | control | 0.796343 | 6.590636 |
| 10 | D4.31 | 0.805230 | 6.207894 |
| 10 | D4.32 | 0.804286 | 6.241939 |
| 20 | control | 0.795366 | 6.599844 |
| 20 | **D4.31** | **0.807751** | **6.076895** |
| 20 | D4.32 | 0.806219 | 6.134368 |

D4.31第20轮对同轮control：126/126条件导数改善，126/126条件边界跳变下降，绝对跳变量宏平均降低7.92%。其归一化光谱MSE约0.00111330、平均光谱MSE约59.5925；第10轮D4.31的归一化MSE略低，control第20轮的平均谱MSE略低，因此不能称所有指标第一。详见 [9组完整摘要](current_configs/D4.35/nine_view_summary.csv)、[逐条件改善数量](current_configs/D4.35/paired_comparison_counts.csv)和 [选择协议](current_configs/D4.31/selection.json)。

生成端仍有明显周期边界异常、122/126条件QQ尾部不足、峰宽IQR比宏平均约1.361。FID未计算。往返检查误差小不等于采样内部保护没有影响。

## 数据划分与复现边界

真实数据126源文件×20条，共2520条。每文件固定12训练／4验证／4测试，共1512／504／504。PCA、先验与归一化仅拟合训练部分。这是同源文件内部划分，不能称为独立批次、独立仪器或未见条件验证。

选择依据来自用户上传的实际报告，结果表哈希与checkpoint登记一致；原始训练权重及数据未传入本次代码更新环境，不声称重新运行了真实GPU实验。统一入口已通过小型合成数据的实际生成、评价及已有回归检查；验证范围记录在发布检查说明中。
