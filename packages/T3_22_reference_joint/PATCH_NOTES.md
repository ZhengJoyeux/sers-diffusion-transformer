# T3.22 文件与修改说明

这是独立实验包，不是覆盖原项目的补丁。旧文件保持原状，新训练权重写入新的outputs目录。

| 文件 | 职责 |
|---|---|
| Model_T3_17.py | 原版主干源码，逐字保持原版本 |
| Model_T3_22.py | ReferenceBank、JointCorrection、ReferenceJointModel；固定参考、联合有界修正、冻结主干 |
| data_t322.py | 精确核对12/4/4划分、固定随机48生成样本身份；原始测量范围mask；仅报告使用标签 |
| Paths_T3_22.py | 保留原始数据路径，维持原有路径种子补尾行为 |
| engine_t322.py | 固定特征缓存、CORN小网络训练、验证选择、零修正回退、独立checkpoint加载、九组合表 |
| T3_22_Training.py | 拟合训练集参考和标准化、复现原模型验证、顺序训练两组、汇总对照 |
| Inference_T3_22.py | 恢复整套checkpoint，对真实验证谱推理；不重新拟合、不评价测试集 |
| T3_17_LR.py | 原版按optimizer更新推进的warmup/cosine辅助函数 |
| prepare_t322.py / experiment_t322.py / run_t322.sh | 隔离快照、指纹保护、check/smoke/train/evaluate/restore入口、日志与报告打包 |
| test_t322.py | 17项人工数据验证，包括两组完整缓存与短训练流程 |
| expected_* / reference_random48.json | 诊断过的源码、原权重、模型配置与数据设置 |
| package_manifest.json / VALIDATION.json | 包完整性指纹与本地验证记录 |

相对旧方案的主要变化：

1. 增加训练集单药参考，不能使用真实验证/测试谱建立参考，不能使用生成谱形成模板或标准化尺度。
2. 原始窗口保留跨谱强度信息，和旧主干的归一化特征共同输入；不是将所有信息重新归一化成同一峰高。
3. 一次读取三药上下文，分别修正6个CORN条件输出；不使用固定的跨药峰高扣除规则、不只修正0.5附近。
4. 先缓存冻结主干输出和query，降低50轮×2组的计算成本；只能优化40,742个新参数。
5. 保存“候选”和“推荐”两个结果，推荐没有通过保守验证规则时回到零修正原模型。
6. 输出重点九组合的修正前后等级计数，避免用总准确率掩盖具体错误迁移。

边界：两个对照都使用原始窗口，因此比较回答的是“在相同联合修正模块中加入参考匹配是否有增益”，不等于比较全部原始输入分支的作用。参考增益是压缩空间辅助量，不能报告为物理浓度。该实验保留原训练集4:1生成/真实样本量关系，不能同时归因于来源重加权。50轮验证选择仍需独立测试及必要的重复种子验证。

操作命令、输出路径、原权重路径和恢复方式见README.md。
