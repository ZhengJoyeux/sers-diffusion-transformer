# D4.44 图像块边界联合建模

这是服务器 D4.44 joint 实验的运行代码。它在二维曲线 DiT 的相邻图像块输出端加入联合边界残差头；控制组不加入该头。T3.33 识别模块保持现有版本。

126 个条件的验证对照中，joint 的原生图像平均一阶导数 Pearson 从 0.8021 提升至 0.8129，每张图检测到的窄尖峰候选平均从 3.32 降至 1.99；这是一次实验的结果，并不证明所有窄峰都是伪峰。尾部失配问题仍在。

## 权重与配置

仓库不包含真实数据、服务器配置或正式权重。已评价的 joint 权重在原服务器的 `~/d4_44_joint_boundary_v1/joint/checkpoints/step_00004750.pt`，报告记录的 SHA-256 为 `4e70a526aea6a41e1fa5316efbce8a7edba751385882678e92dbd26f192e40d3`。该权重必须由 `train_joint.py` 的 joint 入口加载；旧的 D4.31 入口不能加载额外头部。

服务器上运行时，本目录旁需要用户自行提供 `server_config.json`，指定扩散项目、真实数据、初始化检查点等路径。完整的原实验还依赖服务器的实验目录及其运行配置。本仓库未验证在独立机器上的端到端训练或生成；请勿将小模型 CPU 检查理解为 GPU 训练效果验证。

此代码基于用户提供的服务器文件，未包含 D4.46–D4.48 的后处理消融脚本。PNG 输入及纯图像生成识别尚未在本扩展中实现。
